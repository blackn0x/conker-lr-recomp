# Screenshots

The project page ([README](../../README.md)) shows pictures from this folder. Put them here as
PNG files, about 960 px wide, with the file names below. Then remove the `<!-- -->` marks around
the matching lines in `README.md` and `README.uk.md`.

Take the pictures from your own build of the game. Do not add files from the game itself (no
disc images, no extracted textures).

| File | What to show |
|---|---|
| `01-title.png` | The title screen on Game 1 |
| `02-field.png` | Conker in the first field (Hungover), gameplay |
| `03-settings.png` | The in-game settings menu (Esc or Minus) over the game |
| `04-aspect.png` | The same scene in 4:3 and 16:9 side by side |
| `05-cutscene.png` | A cutscene with the depth-of-field blur |
| `06-switch.png` | A Switch in handheld mode running the game |
| `07-windows.png` | The game in a window on Windows |
| `08-subtitles.png` | A speech bubble with the wide subtitle box |
